# Official Phosphor Icons: Cube Focus / Duotone

The shape is the official upstream Phosphor `cube-focus-duotone` vector, with
`currentColor` changed to `#2563eb` for the Better Screenshot Tool theme.

Upstream asset: https://github.com/phosphor-icons/core/blob/main/assets/duotone/cube-focus-duotone.svg
Upstream license: https://github.com/phosphor-icons/core/blob/main/LICENSE

The asset was obtained from the same upstream Phosphor paths republished in the
`phosphor-svgs` Rust crate documentation:
https://docs.rs/phosphor-svgs/latest/phosphor_svgs/icon/cube_focus/constant.DUOTONE.html

Copyright (c) 2023 Phosphor Icons — MIT License (see PHOSPHOR_LICENSE.txt).
Local PNG / ICO sizes are rasterizations of the SVG.

Ribbon variants (16px and 32px) have opaque white backgrounds. The 48px dialog logo and .ico remain transparent. The icon loading code also flattens the ribbon variants to a 24-bit RGB bitmap before OLE conversion.
